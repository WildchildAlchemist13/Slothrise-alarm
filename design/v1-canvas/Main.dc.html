REWARD Wake win + streak Confetti, streak count, the week so far.

UX rules

  1. Half-asleep proof. Wake screens use 56px+ buttons, one main action, no small text.
  2. Friction only at wake time. Missions are hard on purpose. Everything else is one tap.
  3. Show the cost, never shame. Snooze says it breaks the streak before you tap it.
  4. Colour tells time. An alarm’s gradient comes from its hour, so a list scans like a day.
  5. Reward the morning, not the app. The win screen points to the routine, then gets out of the way.
